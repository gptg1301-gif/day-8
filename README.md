# Установка и настройка форума для кулинарного блога

**Тематика сайта:** Кулинария, рецепты, обсуждение блюд  
**Платформа:** WordPress + плагин bbPress  
**Ветка Git:** `feature/forum-setup`

---

## 📋 Пошаговое руководство

### Шаг 1. Установка плагина bbPress

1. В админ-панели WordPress перейдите: **Плагины → Добавить новый**.
2. Найдите `bbPress` → Установить → Активировать.
3. После активации в левом меню появится раздел **«Форумы»**.

> Скриншот: (вставьте `![bbPress installed](screenshots/00_bbpress_installed.png)` если есть)

### Шаг 2. Создание форума

1. Перейдите: **Форумы → Добавить новый**.
2. Название: `Кулинарная дискуссия`
3. Описание: `Обсуждаем рецепты, делимся советами и задаём вопросы`
4. Нажмите **«Опубликовать»**.

![Создание форума]
![Форум опубликован]

### Шаг 3. Добавление форума на сайт

- Через меню: **Внешний вид → Меню** → добавить пункт со ссылкой на страницу форума (обычно `/forums/`).
- Результат: пункт «Форум» отображается в навигации.

![Меню с форумом]

### Шаг 4. Создание категорий

1. **Форумы → Добавить новый**.
2. В правой колонке «Атрибуты раздела» выберите тип **«Категория»**.
3. Названия: `Рецепты`, `Вопросы и советы`, `Кулинарные новости`.
4. Опубликуйте.

![Категории форума]

### Шаг 5. Создание тем (минимум 3)

1. На сайте перейдите на страницу форума.
2. Нажмите **«Создать новую тему»**.
3. Заполните заголовки и содержание:

| Тема | Содержание |
|------|-------------|
| «Как идеально запечь курицу?» | Ищу проверенный способ, чтобы мясо было сочным... |
| «Лучший ПП-десерт без сахара» | Поделитесь рецептами низкокалорийных сладостей... |
| «Секреты домашней пиццы» | У кого получается тонкое хрустящее тесто? |

![Темы форума]

### Шаг 6. Добавление сообщений (минимум 3)

- В каждой теме опубликуйте хотя бы 1 ответ.
- Пример ответа в теме «Как запечь курицу»: *«Попробуйте маринад из йогурта и чеснока на ночь — курица будет очень сочной»*.

![Сообщения]

### Шаг 7. Настройка ролей пользователей

1. Установите плагин **User Role Editor**.
2. Перейдите в **Пользователи → User Role Editor**.
3. Выберите роль `Участник` (Participant) и отметьте права:
   - `read`, `publish_topics`, `publish_replies`, `edit_own_topics`, `edit_own_replies`
4. Нажмите **«Update»**.

![Роли пользователей]

### Шаг 8. Добавление правил форума

- Создайте тему «📜 Правила форума» и закрепите её вверху.
- Текст правил:
  > 1. Уважайте других участников.  
  > 2. Запрещён спам и реклама.  
  > 3. Обсуждаем только кулинарию.  
  > 4. Фото блюд приветствуются.

![Правила форума]

### Шаг 9. Изменение внешнего вида (по желанию)

Добавлен кастомный CSS (через **Внешний вид → Настроить → Дополнительные CSS**), который делает форум более тёплым и «вкусным»: оранжевые кнопки, кремовый фон, скруглённые карточки.
